## 기본 원칙 및 규칙 (영구 적용)
1. **에뮬레이터 즉시 반영 필수**: 별도 언급이 없는 일반 코드 수정 요청 시, 반드시 안드로이드 에뮬레이터에 실시간 핫 리스타트/핫 리로드(반영 완료)까지 완결할 것.
2. **요청한 것만 실행**: 시키지 않은 부가 작업(불필요한 스크린샷 캡처, 다른 파일 임의 수정, 과잉 설명 등) 금지.
3. **다크/라이트 모드 양쪽 동시 대응**: 모든 UI/디자인 작업 시 반드시 다크모드와 라이트모드 양쪽 모두 완벽하게 고려하여 구현.
4. **AAB 빌드 요청 시 자동 완결 프로세스**: AAB 빌드 요청을 받으면 빌드 완료 후 반드시:
   - ① AAB 결과물이 위치한 폴더(Finder) 즉시 열기 (`open build/app/outputs/bundle/release`)
   - ② 출시명 (예: `1.0.0 (Build 번호)`) 출력
   - ③ 간단하고 명확한 출시 노트 (한국어/영어) 함께 출력
