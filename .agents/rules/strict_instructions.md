# 작업 원칙

1. **지시된 작업만 수행**: 사용자가 명시적으로 요청한 작업만 수행하며, 불필요한 부가 작업(자체 화면 캡처, 임의 조작, 과도한 부가 기능 추가 등)은 일체 하지 않는다.
2. **신속하고 간결한 피드백**: 코드 수정 및 요청 사항을 빠르게 처리하고 핵심만 간결하게 보고한다.
3. **화면 테스트는 사용자가 직접 수행 (AI 화면 테스트 금지)**: 작업 완료 후 AI가 임의로 화면 캡처나 에뮬레이터 조작 등 자체 화면 테스트를 하지 않고, 에뮬레이터 실시간 반영(핫 리로드/핫 리스타트)까지만 완료한 뒤 테스트는 사용자가 직접 진행한다.
